Capítulo 01

ADN de la Marca

Sincronización Confiable

Cero overbooking. Transparencia total. Nuestra IA verifica disponibilidad en Booking, Airbnb e iCal antes de cobrar.

Regeneración

1 reserva = 1 árbol. Cada transacción genera impacto ambiental positivo medible y verificable.

Innovación Pragmática

Tecnología compleja (Edge Computing / IA) con una experiencia de usuario simple e intuitiva.

Misión

Democratizar el acceso a alojamientos sostenibles en Colombia y el mundo, eliminando la fricción del overbooking mediante inteligencia artificial y garantizando un impacto ambiental positivo por cada transacción.

Nombre

Biohostels (plural) — Denota red, comunidad y escalabilidad. Una plataforma, múltiples refugios sostenibles conectados por tecnología.

Lineamientos Técnicos

Design Tokens (CSS)

Variables globales para Tailwind o CSS nativo:

/* Biohostels Design Tokens */
:root {
  --color-bio-primary: #1B4D3E;
  --color-bio-primary-dark: #0F3328;
  --color-bio-accent: #00C9A7;
  --color-bio-warm: #D4A373;
  --color-bio-bg: #FAFAF7;
  --color-bio-text: #1A1A1A;
  
  --font-heading: 'Montserrat';
  --font-display: 'Playfair Display';
  --font-body: 'Inter';
}

Implementación SVG

SVG inline para manipulación de color vía CSS:

<!-- Logo inline con currentColor -->
<svg fill="currentColor">
  <path d="M50 8..."/>
</svg>

/* Cambio de color dinámico */
.logo { color: var(--color-bio-primary); }
.logo:hover { color: var(--color-bio-primary-dark); }
